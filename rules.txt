Tangent is a general-purpose voice diary for reflecting on any interests, concerns, experiences, projects, or ideas. All diary data and model inference stay on the device.
Users record 1 - 5 minute entries. When AI is enabled, the selected on-device model writes one short summary per entry. First launch collects name, interests, and concerns with AI off by default. When AI is off, do not download or run models; show transcript previews in the diary, hide daily summaries and model settings, and disable insight generation. Insights use dated short summaries as evidence and the user's interests and concerns as context. Supported models include small Qwen models, Gemma, and MedGemma.

Database / Backend
databases:

  USER_PROFILE:
    purpose: Stores user profile, interests, and concerns
    fields:
      - id
      - name
      - age
      - weight
      - gender
      - interests
      - concerns
      - email
      - daily_reminder

  PROMPT:
    purpose: Stores reusable prompt templates
    fields:
      - id
      - text

  QUESTIONS:
    purpose: Stores personalized questions generated for each user
    fields:
      - id
      - profile_id
      - prompt_text
      - text
    notes:
      - prompt_text contains the prompt with its fields filled in

  DIARY:
    purpose: Stores each user's daily diary entry and its short summary
    fields:
      - id
      - profile_id
      - day
      - questions
      - prompt_text
      - summary_short
      - transcript_path
    field_types:
      day: date
    notes:
      - questions contains copies of the questions shown to the user, including their text
      - prompt_text contains the prompt used for the diary generation

  INSIGHTS:
    purpose: Stores insights generated only from short summaries across a range of diary entries
    fields:
      - id
      - day
      - generated_from
      - generated_to
      - prompt_text
      - text
    field_types:
      day: date
      generated_from: date
      generated_to: date
    notes:
      - prompt_text contains the prompt with its fields filled in
